# Assets

- `sample-colors.png` — the full palette: ground, platform ramp, neutral ramp,
  per-vertical accents, tenant presets, semantic colours.
- `sample-layouts.png` — the Basic-tier profile page at desktop width (1200), the
  reference for the ruled hero, the 440px portrait column and the section rules.
- `sample-components.png` — the homepage at desktop width, the reference for the
  search composite, counts strip, portrait card grid and index blocks.

The layout and component sheets are screenshots of the live mockups, so they are
the current truth rather than a redrawn diagram. The source files are
`Directory Profile Tiers.dc.html` and `Directory Pages.dc.html`.

For the other screens — Professional and Premium profiles, search results, institution,
city index, lawyer landing and pricing, each at both breakpoints — open the two mockup
files directly. They are the authoritative rendering; these PNGs are a quick reference.
